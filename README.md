# Langrisser: Sea of Sword Wiki

Independent English pre-launch guide hub for **Langrisser: Sea of Sword** at
`https://www.langrisserseaofsword.wiki`.

The launch site covers:

- release status, pre-registration and official download safety;
- dual-hero squads, mixed troops and Hero Unity Skills;
- exploration, territory growth and destructible tactical maps;
- confirmed characters, story context and platform status;
- official Windows system requirements;
- clearly labeled unknowns for monetization, summons, tests and launch timing;
- WebSite, Organization, VideoGame, VideoObject, FAQPage, ItemList, Article and
  BreadcrumbList structured data.
