## 页面差距

必须覆盖：

- Wiki 首页与 guides 分类枢纽
- release date / release status
- pre-registration
- gameplay overview
- characters
- platforms
- PC system requirements
- official download
- dual-hero system
- exploration and territory
- story and setting
- free-to-play and gacha status
- Sea of Sword vs Langrisser Mobile

暂缓：

- tier list、reroll、codes
- 单角色与单技能数据库页
- beta schedule、server list、cross-save
- 资源、体力、抽卡与 endgame 指南
- 本地化页面

明确不做：

- cheats、trainer、crack、APK 或修改客户端
- 未经公开资料支持的倒计时、礼包码、排名或奖励表
- 从 Langrisser Mobile 复制的角色、数值与系统结论

## 页面规模建议

首发英文核心内容控制在 14 个游戏意图页面，加隐私、条款、Cookie 和免责声明。后续只在 GSC 出现稳定查询或官方公开可验证系统后拆分新页，避免预发布阶段的薄内容与关键词自相竞争。
